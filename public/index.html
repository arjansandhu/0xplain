0xplain

Pay-per-request transaction intelligence API behind x402.
Decode ERC-20 transactions. Score wallet risk. Paid in USDC on Base.

How it works

1Request endpoint
2Get 402 + price
3Sign USDC payment
4Receive data

GET /explain

$0.001 per request

Submit a transaction hash. Get the token, amount, sender, recipient, gas cost, and a plain-English explanation of what happened.


{
  "transaction": {
    "hash": "0xc6ed46b7...e34b05de",
    "block": 38372100,
    "timestamp": "2026-03-03T04:10:22.000Z",
    "status": "success"
  },
  "decoded": {
    "type": "ERC-20 Transfer",
    "action": "transfer",
    "token": { "symbol": "USDC", "name": "USD Coin", "decimals": 6 },
    "from": "0xfaec...3e1f",
    "to": "0x564b...5798",
    "amount": "20.00",
    "amountRaw": "20000000"
  },
  "gas": { "used": 52000, "price": "0.006 gwei", "costUsd": "$0.0008" },
  "explanation": "This transaction transferred 20.00 USDC
    from 0xfaec...3e1f to 0x564b...5798 on Base Sepolia.
    The transfer cost less than a tenth of a cent in gas."
}

GET /risk

$0.005 per request

Submit a wallet address. Get a risk score (0–1), behavioral flags, counterparty analysis, and an AI-generated risk narrative.


{
  "address": "0x564b...5798",
  "riskScore": {
    "overall": 0.38,
    "level": "MEDIUM",
    "breakdown": {
      "sanctionsExposure": 0.0,
      "scamExposure": 0.0,
      "behavioralRisk": 0.55,
      "counterpartyRisk": 0.25,
      "walletMaturity": 0.65
    }
  },
  "flags": [
    "BRAND_NEW_WALLET: Created 1 days ago",
    "LOW_DIVERSITY: Only 2 unique counterparties"
  ],
  "riskNarrative": "This wallet presents moderate risk
    primarily due to its newness and limited activity..."
}

Agents discover this API via x402. Any request without payment returns 402 Payment Required with USDC payment terms. Compatible agents and wallets pay automatically.
